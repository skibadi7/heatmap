# heatmap
A simple C program that generates a ppm image heatmap for a csv file generated by rtl_power, for use with the RTL-SDR.

It does two passes over the csv file, with the first pass determining the image dimensions and the sample value range.

Axis labels are not supported.

The color map can be configured with the -c option.

The generated image is written to stdout in ppm format and can be converted to png with pnmtopng.

## Usage

```
heatmap [-c color|grey|r1,g1,b1,r2,g2,b2,...] input.csv
```


## Example Makefile

```
%.png : %.ppm
	pnmtopng $< > $@

%.ppm : %.csv
	heatmap $< > $@
```
